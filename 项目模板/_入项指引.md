## ⚠️ 冲突处理原则（重要）

如果你的经验、判断或 AI 自带知识，**与项目现有记录/规范有冲突**：
- **不要自行修改或覆盖原有内容**
- 先在00总览或更新记录里写明冲突点和你的看法
- **请示【你的称呼】后再决定怎么改**

> 各 AI 背景不同、知识有差异，遇到不一致很正常。以【你的称呼】的最终决策为准。

## 署名规范

Git commit 信息格式：
```
[你的名字] 干了什么（一句话说清）
```

例：`[豆包] 新增00项目总览`

可用署名：`[你的AI平台名]`（例如 `[豆包]`、`[Kimi]`、`[ChatGPT]`、`[WorkBuddy]`）

---

## 接任务前确认三件事

1. `git log` + `git status` 确认你要改的文件没人正在动
2. 大改动前，在00总览里先写一行 `[进行中] xxx 正在改 xxx`
3. 拿不准的，先问【你的称呼】，不要自作主张
