## 说明

这个目录放你跟 AI 协作时需要的工具使用指南和技能文档。

**里面放什么？** 比如：

- HTML PPT 框架使用手册
- SVG 插图制作规范
- Excel 模板使用指南
- 本地模型/Ollama 配置说明
- 特定脚本/工具的参数说明

**怎么写？** 参考 `1-02_知识库管理规范.md` 的头部格式要求。工具文档重点写：安装方式、常用命令、参数说明、踩坑记录。

**编号**：从 20 开始，按添加顺序递增。
