# 对话记录归档

> AI对话统一归档目录 · 遵循知识库「AI对话备份与归档规范」

---

## 目录结构

```
对话记录/
├── 01_raw/        ← 原始HTML保真（完整对话，含图片）
├── 02_text/       ← 整理版Markdown（精华内容，可直接引用）
└── README.md      ← 本文件，对话索引
```

---

## 对话索引

| 日期 | 平台 | 主题 | 原始文件 | 整理版 |
|------|------|------|---------|--------|
| YYYY-MM-DD | 平台名 | 主题 | `01_raw/文件名.html` | `02_text/文件名.md` |

---

## 命名规范

- 格式：`YYYYMMDD_平台_主题.扩展名`
- 示例：`20260727_【平台名】_项目规划讨论.html`

---

## 两级分离原则

- **01_raw**：原始保真，不做任何修改，确保可追溯
- **02_text**：人工/AI整理后的精华，方便引用和搜索

详见知识库里的「AI对话备份与归档规范」（统一备份与归档标准，文件名按你的编号体系命名）
