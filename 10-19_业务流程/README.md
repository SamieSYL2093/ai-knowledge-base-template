# 业务流程目录

> 用途：放你自己的业务知识和工作流程规范文档
> 关键词：业务、流程、规范、模板
> 更新：【日期】

## 说明

这个目录放你跟 AI 协作时需要遵守的业务规则和流程文档。

**里面放什么？** 任何你希望 AI 记住并遵守的工作流程。比如：

- 辅导计划/日志的格式规范
- PPT 制作的颜色、字体、动画要求
- 项目文档的目录结构和命名标准
- 数据报告的输出格式
- 客户/项目专用的特殊规则

**怎么写？** 参考 `1-02_知识库管理规范.md` 的头部格式要求。关键要写清楚"❌ 不要怎么做"和"✅ 应该怎么做"。

**编号**：从 10 开始，按添加顺序递增。

## 使用

```
📂 10-19_业务流程/
├── 10_【你的第一份业务规范】.md
├── 11_【你的第二份业务规范】.md
└── ...
```

← 删除本文件，换成你自己的内容。
